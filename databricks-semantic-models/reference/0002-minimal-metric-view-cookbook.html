Minimal Metric View Cookbook

A copy-ready pattern for creating and querying a small Databricks Metric View over samples.tpch.orders.

The Shape

source

samples.tpch.orders

The table-like asset that supplies the raw columns for the Metric View.

fields

Group and filter by

Scalar expressions such as order_month, order_status, and order_priority.

measures

Aggregate with meaning

Aggregate expressions such as order_count, total_revenue, and revenue_per_customer.

Create The Metric View

Replace <catalog>.<schema> with a Unity Catalog location where you have USE CATALOG, USE SCHEMA, and CREATE TABLE privileges.

CREATE OR REPLACE VIEW <catalog>.<schema>.orders_metric_view_min
WITH METRICS
LANGUAGE YAML
COMMENT 'Minimal Metric View for TPC-H order KPIs.'
AS $$
version: 1.1
comment: Minimal order metrics from samples.tpch.orders.
source: samples.tpch.orders
filter: o_orderdate >= '1995-01-01'
fields:
  - name: order_month
    expr: DATE_TRUNC('MONTH', o_orderdate)
    comment: Month when the order was placed.
  - name: order_status
    expr: |
      CASE o_orderstatus
        WHEN 'O' THEN 'Open'
        WHEN 'P' THEN 'Processing'
        WHEN 'F' THEN 'Fulfilled'
      END
    comment: Business label for order status.
  - name: order_priority
    expr: SPLIT(o_orderpriority, '-')[0]
    comment: Numeric priority extracted from the source priority code.
measures:
  - name: order_count
    expr: COUNT(DISTINCT o_orderkey)
    comment: Count of distinct orders.
  - name: total_revenue
    expr: SUM(o_totalprice)
    comment: Sum of order total price.
  - name: unique_customers
    expr: COUNT(DISTINCT o_custkey)
    comment: Count of distinct customers.
  - name: revenue_per_customer
    expr: MEASURE(total_revenue) / MEASURE(unique_customers)
    comment: Revenue divided by unique customers.
$$;

Query Patterns

Monthly trend

SELECT
  order_month,
  MEASURE(total_revenue) AS total_revenue,
  MEASURE(order_count) AS order_count
FROM <catalog>.<schema>.orders_metric_view_min
GROUP BY order_month
ORDER BY order_month;

Status breakdown

SELECT
  order_status,
  MEASURE(total_revenue) AS total_revenue,
  MEASURE(revenue_per_customer) AS revenue_per_customer
FROM <catalog>.<schema>.orders_metric_view_min
GROUP BY order_status
ORDER BY total_revenue DESC;

Filtered question

SELECT
  order_priority,
  MEASURE(order_count) AS order_count,
  MEASURE(total_revenue) AS total_revenue
FROM <catalog>.<schema>.orders_metric_view_min
WHERE order_status = 'Fulfilled'
GROUP BY order_priority
ORDER BY order_priority;

Rules To Remember

Concept
Rule
Example
Source
Use a table-like asset or SQL query. You need SELECT privileges on referenced assets.
source: samples.tpch.orders
Field
A scalar expression used in SELECT, WHERE, and GROUP BY.
order_month
Measure
An aggregate expression. Query it with MEASURE(), not raw SUM() at query time.
MEASURE(total_revenue)
Composed measure
A measure can reference earlier measures using MEASURE() inside the YAML definition.
MEASURE(total_revenue) / MEASURE(unique_customers)
Filter
A YAML-level filter scopes all downstream queries against the Metric View.
filter: o_orderdate >= '1995-01-01'
